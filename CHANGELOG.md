# Changelog

## 0.5.0
- Fundação SQLite com FTS5, fontes, organizações, evidências, lotes de importação, páginas e URLs descobertas.
- Importador IAA XLSX com dry-run e preservação da data histórica do dataset.
- Crawler manual com robots.txt, same-host traversal, limites, validação de URL e bloqueio de hosts privados.
- Extração de metadados e sinais de serviços de imigração.
- Perfis organizacionais e pesquisa textual.
- API FastAPI local com chaves Bearer individuais por consumidor; apenas hashes são guardados.
- CLI e testes offline.
